Controls
  1. Click four corners of the document in any order.
  2. Drag any placed corner to refine it with the loupe.
  3. Use Reset if you want to start over.
  4. Save writes the rectified crop and advances to the next image.
  5. Skip leaves the current image untouched. Quit stops the session.
Aspect Crop
  1. Edit the ratio list in the browser if you want a different target set.
  2. The closest listed ratio is chosen automatically for each image.
  3. Use Shift to slide the crop left or right, or top or bottom, depending on the image.
  4. Use Margin to trim a small percentage from all sides before the aspect crop is chosen.
  5. Save writes the cropped image, Skip leaves it untouched, and Quit stops the session.
